## Mac build notes (Apple clang, macOS 26, Apple Silicon)

- Tools: `brew install cmake pkg-config sdl2 wolfssl expat`; `pipx install --python python3.13 platformio` (pio 6.2.0 under Python 3.14 was not tried). Set `PKG_CONFIG_PATH=/opt/homebrew/opt/expat/lib/pkgconfig`.
- The simulator does not compile with Apple clang as shipped (upstream builds with GCC on Linux). Workaround used, nothing committed:
  `PLATFORMIO_BUILD_FLAGS=-Wno-c++11-narrowing` (3 narrowing errors in `FileBrowserActivity.cpp`, `PokemonActivity.cpp`) and a one-line local edit in `src/activities/home/HomeActivity.cpp:2274` (`pokemonAccessoryRect_ = {};` to `= Rect();`, because `Rect`'s constructor is `explicit`). Homebrew GCC 15 does not work with the macOS SDK headers.
- `pio run -e pokemon-x4-pro` deletes the simulator build dir; rebuild the simulator after a firmware build.
- Pokémon art is not in git: unzip `xteink-pokemon-sd-card-assets.zip` from the upstream release into `fs_/` (gives `fs_/pokemon`).
- Screenshots need SDL's default video driver (a window opens briefly); `SDL_VIDEODRIVER=offscreen` wrote none on macOS. A frame must be redrawn after the screenshot time, so schedule a key press after it. `CROSSINK_SIMULATOR_START_POKEMON` belongs to the smoke test (it exits by itself); for a real-save session boot to Home and navigate with `CROSSPOINT_SIM_INPUT_SCRIPT` (e.g. `3000:BACK;5000:UP;7000:ENTER`; BACK first, because the copy lacks the last-open book and shows an alert).
- Run the simulator against a copy of `fs_` (`CROSSPOINT_SIM_SD=<copy>`), so the fixture in `fs_/.crosspoint` stays pristine.
- X4 Pro Pokémon menus are touch grids: `DOWN` does not move the selection there. Use `TAP:x,y` in logical pixels (portrait 480x800): menu Settings `356,317`; Settings rows and Extras rows are 64 px apart starting at `238,125` (Extras row `238,445`).
- `test/pokemon_extras_compat` can check any save copy: `CROSSINK_EXTRAS_COMPAT_SAVE_DIR=<copy>/.crosspoint` (in memory, never writes), plus `CROSSINK_EXTRAS_COMPAT_CHECK_ONLY=1` to only decode the main save after a simulator session.

## Linux workspace notes (chat session, Ubuntu 22.04 aarch64, GCC 11)

M2's hooks, tests, simulator gate and firmware size were done in the chat workspace's Linux VM, not on the Mac. What it took, nothing committed:

- The PlatformIO registry is not reachable there, GitHub is: `pio pkg install -g -p https://github.com/platformio/platform-native.git`, and copy `.pio/libdeps/<env>` from the Mac build instead of downloading the libraries.
- glibc 2.35 has no `strlcpy`/`strlcat`: `PLATFORMIO_BUILD_FLAGS="-include <shim.h>"` with two inline functions. Changing that variable changes the project checksum, and PlatformIO then deletes the whole build dir.
- Screenshots: `SDL_VIDEODRIVER=offscreen SDL_RENDER_DRIVER=software` (the simulator asks for an accelerated renderer; with the hint SDL uses the software one).
- A sleep screen is only presented once, right before deep sleep: schedule its screenshot 2 to 60 ms after the `SLEEP` action and check in the log that `Saved screenshot` comes after `Entering activity: Sleep`.
- In the reader, `RIGHT` turns the page and `BACK` returns Home; taps on the page did not turn it.
- `pio run -e pokemon-x4-pro` needs `SdFat` in the project's own `.pio/libdeps` (`scripts/patch_sdfat.py`), so build the firmware from a clone with the libdeps copied into it, on the branch whose name should appear in the version string.
- The host tests need OpenSSL headers only for `clipping_store`: a small CMake project that adds just the `pokemon_*` test folders builds without them.

## Linux workspace notes, M4 (chat session, Ubuntu 22.04 aarch64)

The VM was fresh, without SDL, OpenSSL or wolfSSL headers. What it took, nothing committed:

- Background processes die when each shell call ends (at most 3 minutes); run long builds in repeated slices.
- SDL 2.0.20 headers from GitHub plus an `sdl2-config` shim pointing at the system `libSDL2-2.0.so.0`; screenshots need `SDL_VIDEODRIVER=dummy` (offscreen is not compiled into the system SDL).
- OpenSSL 3.0.2 headers (`./Configure linux-aarch64 no-asm && make build_generated`) plus a `.pc` file for the system libssl/libcrypto.
- wolfSSL v5.7.6 built with CMake (`OPENSSLEXTRA AESCTR AESGCM KEYGEN CURVE25519 HKDF PKCS12 CERTGEN DES3`), with the `#undef _GNU_SOURCE` line removed from the installed `options.h` (it breaks `<mutex>`).
- The strlcpy shim must use builtins only (no `#include`).
- Copy `.pio/libdeps/<env>` from the Mac and rewrite the `cwd` in each `.pio-link` file.
- In the reader, the X4 Pro drawer has no "Mark finished" row for the fixture EPUB; the gate set `longPressMenuAction` to 8 (Mark finished) in both copies and used `ENTER:1500`. Home's Pokémon row is `TAP:200,335`.
